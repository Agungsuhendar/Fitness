# FitLife — Fitness & Gym Management System

A web-based fitness and gym management application built with **Laravel**.

This project started as a way to explore modern Laravel development while building something practical around fitness and gym management.

After many years away from PHP, this project has also been a personal journey back into the PHP ecosystem.

## ✨ About FitLife

FitLife is a web application designed to support day-to-day fitness and gym operations.

The project explores how a modern web application can bring together members, memberships, training programs, and gym management into a single platform.

The application is still evolving, with new features and improvements being added along the way.

## 📚 Background

This project has a little personal story behind it.

I first learned PHP around **2005**, when I was still in vocational high school.

Back then, web development was very different.

PHP, HTML, CSS, MySQL — and a lot of things were done manually.

Around 2009, I moved on to other technologies, mainly **Java** and later **.NET**.

PHP eventually became something I used to know.

Then, in 2026, I started working with PHP again.

This time, through Laravel.

It was interesting to see how much the ecosystem had changed while still finding some familiar pieces from the technology I first learned almost two decades ago.

FitLife is one of the projects I built as part of that journey back to PHP.
